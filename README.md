# NervixPay desktop releases

Official signed and Apple-notarized macOS downloads for NervixPay. Application source is maintained separately.

## Download v2.1.2

- [macOS universal DMG](https://github.com/DansiDanutz/NervixPay-Releases/releases/download/desktop-v2.1.2/NervixPay-v2-2.1.2-macOS-universal.dmg)
- [macOS universal ZIP](https://github.com/DansiDanutz/NervixPay-Releases/releases/download/desktop-v2.1.2/NervixPay-v2-2.1.2-macOS-universal.zip)
- [SHA-256 checksums](https://github.com/DansiDanutz/NervixPay-Releases/releases/download/desktop-v2.1.2/SHASUMS256.txt)
- [Release notes and verification](https://github.com/DansiDanutz/NervixPay-Releases/releases/tag/desktop-v2.1.2)

Quit an older Nervix Pay app before installing. Open the DMG and copy NervixPay v2 into Applications, or extract the ZIP and move the app there. v2 is installed separately from the older application. Browser sign-in must return to NervixPay v2 through the nervixpay:// link handler.

The 2.1.2 package includes Apple Silicon and Intel architectures. The earlier 2.0.0 release was tested with all three sign-in providers on Apple Silicon and under Rosetta for its packaged smoke checks. Physical Intel testing and sign-in on the exact 2.1.2 release remain unverified.
